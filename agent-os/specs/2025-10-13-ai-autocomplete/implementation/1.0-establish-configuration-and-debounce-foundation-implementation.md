## Implementation Summary
The autocomplete configuration globals were documented and deduplicated so users can confidently override enablement, debounce timing, scope filters, large-file safeguards, and context sizing. This keeps configuration aligned with existing plugin patterns while making the defaults explicit.

Vimscript event handling now resets timers only for normal buffers, safely reschedules requests after active runs, and feeds the Python pipeline the configured context window. Python-side unit tests were extended to cover normal-buffer eligibility checks and to assert that request orchestration honours context overrides using the provider abstractions.

## Key Implementation Details

### Config Defaults Consolidation
**Location:** `autoload/vim_ai_config.vim`

Removed duplicate definitions and documented the autocomplete globals so defaults are clear and user overrides remain straightforward.

**Rationale:** Ensures a single source of truth for autocomplete toggles and timing, aligning with the plugin's configuration conventions.

### Debounce & Pipeline Rescheduling
**Location:** `autoload/vim_ai_autocomplete.vim`

Event handling now cancels timers when buffers fall out of scope, defers scheduling while a request is active, and reschedules once the active request finishes when new activity occurs.

**Rationale:** Prevents missed completions during bursts of edits and guarantees requests only originate from normal buffers that satisfy whitelist, blacklist, and size checks.

### Autocomplete Request Orchestration Tests
**Location:** `tests/autocomplete_test.py`

Extended unit tests to guard normal-buffer eligibility and to verify that context line overrides propagate to the provider payload via the existing context helpers.

**Rationale:** Validates the core pipeline behaviour without exercising the full suite, matching the task mandate.
