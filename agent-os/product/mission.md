# Product Mission

## Pitch
Vim AI is a Vim/Neovim plugin that helps Vim and Neovim users bring AI directly into their editor workflows by enabling code and text generation, in-place editing, interactive chat with GPT models, and vision/image features — all via OpenAI-compatible APIs and provider plugins.

## Users

### Primary Customers
- Individual Developers: Daily Vim/Neovim users who want faster coding, refactoring, and documentation generation without leaving the editor.
- Teams and Power Users: Small teams and advanced users who want consistent, configurable AI tooling integrated into their existing editor workflows.

### User Personas
**Backend Developer** (25–45)
- **Role:** Full‑time developer using Vim for daily coding
- **Context:** Works on service code, tests, and infra scripts
- **Pain Points:** Context‑switching to external AI/UIs; repetitive edits and boilerplate
- **Goals:** Speed up routine edits, get context-aware suggestions, and reduce friction for quick prototypes

**DevOps Engineer** (25–45)
- **Role:** Maintains deployment scripts and configs in Vim
- **Context:** Edits YAML, shell scripts, CI configs regularly
- **Pain Points:** Error-prone copy/paste and manual updates; slow iteration on config changes
- **Goals:** Quickly generate and validate snippets, and apply precise edits in-place

## The Problem

### Context Switching & Slow Iteration
Developers frequently leave the editor to use web AI tools or separate apps for generation, editing, or vision tasks, which interrupts flow and slows iteration. This results in wasted time and reduced productivity.

**Our Solution:** Integrate AI capabilities directly into Vim/Neovim so users can generate, edit, and converse with models in-context, minimizing context switches and accelerating common workflows.

## Differentiators

### Editor‑First, Configurable AI
Unlike standalone web tools or heavy IDE plugins, Vim AI is lightweight, editor-native, and highly configurable. It supports OpenAI‑compatible APIs and provider plugins, giving users flexibility and control while preserving the speed and minimalism of Vim.

## Key Features

### Core Features
- **In‑editor Generation:** Generate code, documentation, or text from prompts without leaving the editor — speeds prototyping and reduces manual typing.
- **In‑place Edits:** Apply AI-powered edits to selected text or ranges to refactor, simplify, or transform content quickly.
- **Interactive Chat:** Conversational interface with GPT models for iterative problem solving and exploring solutions.

### Collaboration Features
- **Custom Roles & Presets:** Save and share role definitions and prompt presets to standardize workflows across users or teams.

### Advanced Features
- **Provider Plugins & API Compatibility:** Integrates with any OpenAI‑compatible API and supports third‑party AI provider plugins for flexibility.
